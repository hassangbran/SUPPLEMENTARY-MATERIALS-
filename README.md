\The Supplementary Materials comprise twelve sections (S1–S12) that document the methodological and data-related foundations of the review. S1 provides the complete search strings used in Scopus, Web of Science, and IEEE Xplore. S2 details stopword lists, stemming rules, and deduplication protocols. S3 presents the VOSviewer configuration parameters and the thesaurus file. S4 contains the MATLAB scripts employed for duplicate elimination, terminology harmonization, co‑occurrence matrix generation, and temporal trend visualization. S5 includes the full coding dataset for the 30 core studies, while S6 reports the detailed MMAT scores. S7 provides the PRISMA 2020 checklist, S8 the pairwise Jaccard coefficients, and S9 the annual publication data used for the Mann‑Kendall trend test. S10 lists the studies contributing to each IQR value, S11 offers the dimensional verification table for the four core dimensions, and S12 summarizes the data provenance for all figures. Together, these materials ensure reproducibility, transparency, and methodological rigor.
